一、界面介绍
图 1 主界面
①标题栏
显示软件及相机信息，包括软件版本、相机ID、FPGA版本、Firmware版本、USB连接状态等。对于2025年6月20日之后的版本，EZCAP_QT打开通过光纤连接的相机时，Firmware版本将被替换成PCIE光纤板卡的内部程序版本。
②菜单栏
包含文件操作、相机操作、软件操作等功能菜单选项。
③参数设置菜单
控制拍摄时用于设置相机参数，单帧拍摄模式和连续拍摄模式下显示的菜单列表会有所差异，具体差异详见功能介绍。
③图像显示区域
显示图像数据。
⑤状态栏
显示相机及图像的状态或信息。
二、功能介绍
单帧拍摄功能
连接相机
启动软件后点击菜单栏中“相机菜单”中的“Connect to Single Alt+S”选项，点击后软件将自动扫描并连接相机设备，若相机支持多个读出模式或在电脑上同时连接多个相机，连接相机时将会弹出窗口供用户选择目标相机或读出模式。
图 2 连接相机
图 3 读出模式选择界面
图 4 相机选择界面
预览模式
拍摄预览图像，此模式与调焦模式和拍摄模式互斥，每次只能使用三个中的一个模式进行拍摄。此模式下默认以相机支持的最大BIN合并倍数拍摄，此模式下可以执行单次预览拍摄、连续预览拍摄、参数设置、画辅助线等。
图 5 预览模式菜单
增益设置
可以直接输入增益值或拖动滚动条进行设置，文本框输入参数值时会自动生效，无需按下回车键。此参数值不会在关闭软件时保存到配置中，但是启动软件时会采用与拍摄模式相同的参数值。
图 6 预览模式增益设置
偏移量设置
可以直接输入Offset值或拖动滚动条进行设置，文本框输入参数值时会自动生效，无需按下回车键。此参数值不会在关闭软件时保存到配置中，但是启动软件时会采用与拍摄模式相同的参数值。
图 7 预览模式Offset设置
曝光时间设置
可以直接输入曝光时间值或拖动滚动条进行设置，文本框输入参数值时会自动生效，无需按下回车键，预览拍摄模式下曝光时间单位固定为毫秒。此参数值不会在关闭软件时保存到配置中，但是启动软件时会采用与拍摄模式相同的参数值。
图 8 预览模式曝光时间设置
辅助线设置
单次预览拍摄完成后或连续预览拍摄过程中，可以选择在图像显示区域绘制辅助线，目前支持十字、网格、同心圆三种辅助线。
图 9 预览模式辅助线
单次预览拍摄
点击Preview按键可以进行单次预览拍摄，拍摄采用单帧拍摄模式，拍摄完成后会在图像显示区域显示图像，图像尺寸会显示在软件状态栏，鼠标悬浮于图像显示区域时，鼠标指向的像素值会显示在软件状态栏上，另外此模式下拍摄将应用最大BIN倍率设置。
图 10 预览模式拍摄展示
拍摄完成后，可以通过鼠标左键点击图像显示区域以框选指定位置，此位置信息可以与调焦模式联动，框选完成后鼠标右键点击图像显示区域，在右键菜单中选择“Go Focus Center”，可以前往调焦模式，此时可以以此为止信息进行调焦拍摄。
图 11 框选及调焦模式联动
连续预览拍摄
点击False Live按键可以进行连续预览拍摄，此时按键变成黄色，且无法进行单次预览拍摄，再次点击False Live按键可以退出连续预览拍摄，拍摄过程中会在图像显示区域显示图像，图像尺寸和已拍摄图像帧数会显示在软件状态栏，鼠标悬浮于图像显示区域时，鼠标指向的像素值会显示在软件状态栏上，与单次预览拍摄相同，此模式拍摄同样应用最大BIN倍率设置。
此模式虽然效果上看起来像是连续模式拍摄，但是实际上拍摄仍然采用单帧模式，只是通过重复进行单帧拍摄的方式实现伪连续拍摄效果，此拍摄模式的存在意义是由于早期老款CCD相机只支持单帧拍摄模式，无法进行连续拍摄，因此采用这种方式来提高调焦效率。当连接老款CCD相机调焦时可以先进行连续预览拍摄，粗调焦距，粗调完成后退出连续预览拍摄，控制鼠标点击图像显示区域，框选目标区域，框选完成后鼠标右键点击图像显示区域，选择“Go Focus Center”前往调焦模式进行精确调焦。
目前CMOS相机都支持连续模式，可以直接使用连续模式进行调焦，连续模式具体使用方法请查看连续拍摄功能介绍，因此对于CMOS相机，此拍摄模式仅用于相机测试或其他功能验证。
图 12 连续预览拍摄模式展示
调焦模式
调焦模式用于在较小视野内快速评估星像尺寸与对焦趋势。进入该模式后软件会自动将 ROI 缩减到图像中心附近的 200 行窗口，并以当前 BIN 倍率显示，从而在不改变正式拍摄参数的情况下获得更高的刷新速度和更精确的 FWHM 反馈。
增益设置
调焦模式的增益滑块与输入框独立于预览/拍摄模式，调整后的数值会立即写入相机并在本次会话中记忆。建议以与拍摄模式相同的增益为起点，再根据星点饱和程度细调，避免因信噪比过低导致 FWHM 曲线不稳定。
偏移量设置
Offset 控制用于抬升黑场基线以便观察暗背景。滑动条与输入框即时生效，并会同步到调焦助手的拉伸 LUT。若调焦时背景出现负值或直方图贴边，可适度增加 Offset，完成后再切回拍摄模式的默认设定。
曝光时间设置
调焦模式下曝光单位固定为毫秒，滑块覆盖 10~1000 ms 的常用调焦范围，也可直接在输入框中输入更长曝光，系统会自动限制在相机允许的区间以防配置异常。
单次调焦拍摄
点击 Focus 按钮会执行一次完整的单帧采集，曝光完成后自动刷新状态栏尺寸与直方图，并与 Preview 页联动。可在图像上拖拽矩形框选目标区域，随后右键选择“Go Focus Center”，即可将该区域设为后续调焦中心，实现预览到调焦的无缝切换。
连续调焦拍摄
点击 Live 按钮可进入连续调焦模式。按钮点亮后软件会循环执行单帧曝光并在后台自动调节 ROI，直到再次点击 Live 停止。Live 状态下 Preview/Capture 页签被锁定，增益、Offset、曝光等参数的任何修改都会在下一帧立即生效，方便快速寻找最佳焦点。
调焦助手
调焦助手面板提供 1:1 放大的星点窗口、FWHM 曲线及峰值强度读数，Linear/Thermal/False/Invert 四个伪彩按钮可快速切换显示效果。FWHM 与 Peak 数值滚动显示，当曲线达到最低并稳定时即可判断焦点准确。
拍摄模式
拍摄模式用于执行保存图像所需的标准曝光流程。该模式会恢复全幅 ROI，并联动机械快门、滤镜轮、温控和计划任务等通道，确保与批量输出保持一致。
增益设置
拍摄模式的增益滑块支持 0~最大值的精确输入，修改后立即下发到硬件并写入配置文件，便于下次启动沿用。对于具备双增益通道的机型，可结合读出模式选择最佳信噪比。
偏移量设置
Offset 会影响 16bit 数据的黑电平与直方图拉伸。建议在完成暗场校准后，根据直方图的黑场位置微调 Offset，保证 FIT 图像拥有足够的动态余量。
曝光时间设置
拍摄模式可通过单位下拉框在毫秒、秒、分钟之间切换。曝光阶段的进度条实时显示百分比，结束后自动进入下载阶段，状态栏同步提示“Downloading...”，便于掌握流程。
BIN设置
Capture 页签提供 1×1、2×2、3×3、4×4、6×6、8×8 等 BIN 选项。切换 BIN 会重配 ROI、滚动条与缩略图比例，并在保存文件名中追加 BIN 标记，方便区分不同分辨率的数据。
拍摄图像
按下 Capture 即可开始一次正式曝光。系统会依次设置机械快门、高速读出、延时等参数，并刷新曝光/下载两条进度条。成功下载后会自动更新屏幕视窗、直方图与状态栏尺寸信息，并在需要时触发自动直方图拉伸。
终止拍摄
曝光或下载阶段均可点击 Stop。软件会调用 CancelQHYCCDExposingAndReadout 终止曝光并复位状态机，若处于计划拍摄流程还会设置强制停止标记以确保线程安全退出。
ROI
ROI 面板用于控制工作分辨率。图示区域实时显示当前 ROI 在全幅中的位置，便于确认是否覆盖目标。
默认设置选项
下拉框默认提供 100%、80%、50%、30%、10% 五档居中 ROI，可一键切换常用画幅。选择任意预设后软件会自动计算偏移量、重配分辨率并重绘示意图，连续模式下会自动重启采集线程以应用新 ROI。
设置自定义ROI
选择“Customed”后可输入宽度与高度，点击 Set ROI 即可居中套用。点击 Save ROI 可以把当前 BIN 下的 ROI 组合写入配置文件，列表会为每个 BIN 维护独立的收藏项，下次直接选择即可复用。
缩略图
Screen View 缩略图展示整张图像及当前显示窗口的位置，拖拽缩略图中的取景框即可平移主视窗，适合在高放大倍率下快速定位目标。
直方图
Histogram 面板展示灰度分布，并提供黑/白场指示线与细调按钮。通过《》《》按钮可粗调黑白场位置，Auto 会按照所选算法自动计算伸展区间。
拉伸直方图
手动拉伸时可先用粗调按钮调整大致范围，再配合黑白两个微调按钮精确匹配背景和亮星位置，调整结果即时同步到调焦助手和主显示。
自动拉伸
Auto 按钮会参考 `cBox_autoStretchList` 中的策略（线性、对数、S 曲线等）重新计算黑白点，适合长时间监控或批量输出 JPG/PNG 时保持稳定的屏幕亮度。
保存图像
保存面板负责管理快照与视频输出，所有数据默认写入“桌面/EZCAP Captures/”目录，并在状态栏提示最近一次的保存路径。
打开存储路径
点击“Open Save Folder”可直接用系统资源管理器打开当前存储目录。如目录不存在，软件会自动创建 Images 与 Videos 子文件夹。
保存图像
“Snapshot” 按键依据下拉框格式（JPG/PNG/BMP/TIFF/FIT）保存当前帧，命名规则包含相机型号与时间戳；若选择 FIT，会连同 FIT Header 元数据一并写入。“Start Capture” 用于录制连续视频，再次点击即可停止并恢复快照按钮。
编辑FIT格式图像头信息
在 `File → FIT Header Editor` 中可增删 FIT 关键字，默认包含 DATE-OBS、Gain、Offset、XBINNING、OBJECT、OBSERVER 等字段。修改后点击 Apply 即写入内存，后续所有 FIT 输出都会携带最新的头信息。
计划拍摄
选择 `Planner → Show Plan Table` 打开计划窗口。表格列出 BIN、曝光、重复次数、滤镜槽位、延时、增益及是否启用平均/暗场/偏置扣除，勾选行首复选框即可启用对应任务。右侧可设置输出文件夹及文件名前缀（NGC/M/IC 等快捷按钮），Start 后系统会把任务写入 `Script.ini` 并按顺序执行，期间以颜色标记当前行，完成后恢复 GUI 状态。
图像处理
`Image Process` 菜单提供常用后处理入口。`Noise Analyse` 可实时计算噪声、RMS 与 Overscan；`Image Rotate`、`Image Mirror` 子菜单可对屏幕显示进行 90°/180° 旋转及水平/垂直镜像，操作不会影响 FIT 原数据但会影响屏幕截图。Batch Process 入口在启用批量插件后可用于离线处理。
相机设置
`Camera Setup` 菜单汇集硬件相关工具：`Favorite` 调整 USB Traffic、Fine Tone 及 Trigger In/Out；`GPS Control` 同步经纬度与 UTC 并写入 FIT；`Burst Control`/`Trigger Control` 配置高速连拍与外触发序列；`PHD Link` 与 PHD2 交换导星信息；`Temp Control` 设定 TEC 目标温度并监控功率；`Filter Wheel Control` 管理滤镜槽位并与 Planner 保持一致。
工具
`Tools` 菜单包含 `CapCalibration`（批量拍摄 Dark/Flat/Bias 并自动累计）、`FrameCalibration`（加载既有暗场/平场进行实时扣除）以及 `Correct Center`（在主屏覆盖可定制的同心圆辅助线，便于校准光轴）。
语言设置
`Language` 菜单提供 English、简体中文、日本語、France、Spain、Russia、Germany 七种语言。选择后软件会重新加载对应翻译文件，并在下次启动时自动应用。
帮助
`Help` 菜单包含 About（显示版本、固件、USB 状态）、Manual（打开本手册）、TechnicalSupport（快速查看联系方式）以及多个硬件测试项（Test Mode、Test Guid、Pump V2 等）。启用测试前系统会弹窗确认，以防误操作。
连续拍摄功能
当使用“Camera → Connect to Live”或连接仅支持连续模式的 CMOS 相机时，会进入连续拍摄模式。此模式下图像流由 Live 线程实时刷新，可配合 ROI、缩放与直方图即时查看星场动态。
设置
Live 控制面板分为 Image Format 与 Camera Setup 两部分：前者可选择读出模式、Bin、位深与彩/黑输出；后者提供曝光、增益、Offset、USB Traffic、DDR/AMPV 以及 Gamma/USB 供电等参数。调整滑块或输入框后设置立即生效，状态栏实时显示帧率。点击 False Live 或主界面的 Live 控件即可开始/停止直播。
通用功能
以下功能在单帧与连续模式中均可使用，用于调节显示、校准硬件及完善数据记录。
图像旋转
在 `Image Process → Image Rotate` 中可选择 Rotate90L、Rotate90R、Rotate180，以修正望远镜翻转带来的画面方向。旋转仅影响显示与屏幕截图，不会改写 FIT 数据。
图像镜像
`Image Process → Image Mirror` 提供水平（MirrorH）与垂直（MirrorV）镜像，适合矫正焦平面反射或光路镜像后的左右颠倒。
GPS
打开 `Camera Setup → GPS Control` 可实时读取外接 GPS 的经纬度、UTC，自动写入 FIT Header，并在连拍线程中为每帧记录本地时间戳。
外触发
`Camera Setup → Trigger Control` 配合 `Favorite` 面板可配置 TTL/OC 接口、电平极性及触发源。勾选 Trigger In 后相机会等待外部脉冲曝光；启用 Trigger Out 则在每帧曝光时输出同步信号供其他设备使用。
温控
`Camera Setup → Temp Control` 显示传感器温度、TEC 功率与目标设定，支持设置闭环目标温度、冷却速率及安全上限。超温或超功率时会在状态栏与日志中提示。
滤镜轮
通过 `Camera Setup → Filter Wheel Control` 可检测滤镜轮型号、槽位数量并手动切换位置，支持为各槽位命名并与 Planner 中的 CFW 列联动。
拍摄校正图像
`Tools → CapCalibration` 支持批量采集 Dark/Flat/Bias。选择类型与帧数后点击 Start，软件会自动累计帧数、保存到 `EZCAP Captures/Calibration/`，完成后弹出保存目录。
图像校正
`Tools → FrameCalibration` 允许加载已拍摄的校正帧，并启用 Dark Cal 或 Frame Cal 以实时扣除暗电流与像素响应不均，结果会同时应用于显示与保存的 JPG/PNG。
图像缩放
`Zoom` 菜单提供 0.25X~2X、Fit Window、Fill Window 及 1X 模式。缩放设置会同步控制滚动条范围与缩略图取景框大小，方便在不同分辨率下浏览。
语言
同上所述，`Language` 菜单可在多语言之间切换；需要恢复默认时选择 English 并重启软件即可。
关于
`Help → About` 展示软件版本、相机固件、FPGA、USB 状态，便于技术支持定位问题；`Manual` 打开用户手册，`TechnicalSupport` 列出官方邮箱、论坛与工单入口。
其他
`Help` 菜单中的 Test Mode/Test Guid/Test Pump V2 等选项用于硬件调试，普通用户无需启用。`Debug` 选项会显示额外日志窗口，建议在与工程师联调时打开。
